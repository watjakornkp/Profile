# Watjakorn Glinrakont — Portfolio

🌐 **Live Site**: [watjakornkp.github.io/Profile](https://watjakornkp.github.io/Profile/)

## About

Personal portfolio website showcasing my professional experience, skills, and projects as an IT Professional & System Analyst.

## Features

- ✨ Minimal & Clean design with warm beige accent
- 📱 Fully responsive (mobile, tablet, desktop)
- 🚀 GitHub API integration to display latest projects
- ⌨️ Typing animation effect
- 🎯 Smooth scroll & reveal animations
- 📬 Contact form with mailto integration

## Tech Stack

- HTML5 (Semantic)
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- [Inter](https://fonts.google.com/specimen/Inter) font via Google Fonts
- GitHub REST API

## Setup

Simply open `index.html` in a browser, or serve via any static file server.

## Deploy on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site will be live at `https://watjakornkp.github.io/Profile/`
